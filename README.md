# Social Knowledge

A Markdown-first knowledge repository for capturing, structuring, and reusing social-media and web content.

## Architecture

- GitHub: canonical knowledge repository
- Google Drive: binary asset repository
- Obsidian: human-facing note interface
- ChatGPT Work: capture, curation, and library workflow

## Core principles

1. Preserve source content separately from AI interpretation.
2. Use metadata for semantic classification.
3. Prefer controlled vocabulary over free-form tags.
4. Keep notes portable across Markdown-compatible tools.
5. Treat Source Notes and Insight Notes as different knowledge units.

See `PROJECT.md` and `WORK_INSTRUCTIONS.md` for details.
